# Data

The datasets this project was developed on are **not included** in this
repository:

- The report free text derives from **TCGA pathology reports**. TCGA clinical
  data is public, but redistributing a bulk-processed copy here adds tens of
  megabytes with no code-review value. Reports can be obtained from the
  [GDC Data Portal](https://portal.gdc.cancer.gov/) or
  [cBioPortal](https://www.cbioportal.org/); the results in the top-level
  README are based upon data generated by the
  [TCGA Research Network](https://www.cancer.gov/tcga).
- The feature **annotations** were hand-labeled by a six-person team and are
  their work product; they are not published without the annotators' consent.

## Schema

Training expects a CSV with a free-text column and seven label columns:

| column | type | example |
|---|---|---|
| `patient_id` | string | `TCGA-D7-8573` |
| `text` | string | full pathology report text |
| `sex` | label | `male` / `female` / `unk` |
| `cancer_type` | label | TCGA study code, e.g. `stad`, `brca` |
| `treatment` | label | `resection`, `chemo`, ... / `unk` |
| `tumor` | label | `yes` / `no` / `unk` |
| `tumor_location` | label | anatomical site, e.g. `stomach` |
| `metastasis` | label | `yes` / `no` / `unk` |
| `metastatic_site` | label | site or `n/a` / `unk` |

Labels are normalized (trimmed, whitespace-squeezed, lowercased; missing ->
`unk`) by `src/train.py` before use.

## Synthetic demo set

`sample_annotations.csv` contains six fully synthetic pathology-style reports
(marked as such in their text; two cancer types, breast and lung) so the
pipeline and tests run out of the box with no external data:

```
python src/train.py --data data/sample_annotations.csv --test-size 0.34
```

It exists to demonstrate the interface and keep CI self-contained - six rows
cannot and do not demonstrate model quality.
